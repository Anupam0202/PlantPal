# ADR-0004: Typed in-repo message catalogues instead of Paraglide

- Status: Accepted
- Date: 2026-10-27

## Context

The specification suggests Paraglide JS. Paraglide 2 loads its message-format plugin through `project.inlang/settings.json` modules that are fetched from a CDN at build time. That makes builds non-hermetic and fails on restricted CI networks.

## Decision

Messages live in `apps/web/src/i18n/{en,hi,es}.ts`. English is the base; `Messages` is derived from it, and every other locale must implement the full shape (the TypeScript compiler fails on a missing or extra key). `useT()` returns the catalogue for the current locale; `useFormat()` wraps `Intl` number, date, time and list formatting. Scientific names are never translated.

## Consequences

- Zero runtime dependency, fully typed keys, hermetic builds.
- No ICU plural syntax in strings; plurals use `Intl.PluralRules` in small helper functions where needed.
- Hindi and Spanish are draft translations marked `NEEDS_HUMAN_REVIEW`.
- The catalogues are bundled together today (small); split them per locale if they grow past ~20 kB gzip.
